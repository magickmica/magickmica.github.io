Questions ✦

Is the Magick Mica AI Academy free?

Yes. It's free for Magick Mica newsletter subscribers, and subscribing on Substack is free too.

Do I need to know how to code?

No. The Academy starts from zero with what AI is and how to talk to it. The Claude Code Garage teaches files, HTML, CSS and JavaScript one small step at a time.

What is MCP?

MCP, the Model Context Protocol, is an open standard that lets AI apps connect to tools and data. The MCP Portal explains clients, servers, tool calls, permissions and security in plain language.

How long are the lessons?

A few minutes each. The Daily Signal is a two-minute lesson a day with a streak counter, if you like a little routine.

Why does it look like a computer from 1998?

Because learning feels better when it's playful. The Academy runs on MagickOS 98, the same retro desktop as Magick Mica's MagickOS 98: icons, windows, a Start menu and a taskbar.
