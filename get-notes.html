good to know

Is anything sent to Magick Mica or anyone else?

No. The collector talks only to Substack, from your own logged-in browser, and saves the file to your computer. Merging and exporting happen on this page, in your browser. Nothing is uploaded anywhere.

How does the second time work?

Keep the JSON from step 4. Next time, choose I have a file and drop it in. We find your newest note and make a collector that stops a few days before it, so it's quick. Then drop the new file in step 3 and save the combined JSON again.

Can I collect someone else's notes?

It's built for your own notes. It reads the same public profile feed Substack shows on a notes page, so please only use it for accounts that are yours.

What's in the file?

For each note: its date, text, hearts, restacks and replies, the first image, a video still, any link it shares, and the note's address on Substack.

It stopped partway, or the counter never appeared.

Make sure you're on Substack and logged in — either substack.com/@you/notes or your newsletter's own /notes tab is fine. If Substack stops answering partway, you still get a file with what was collected. Run it again as an update to fill the rest.
